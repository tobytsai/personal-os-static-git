📡 我的追蹤頻道

把常看的頻道變成自己的卡片，可依藝術、地方創生、教育、AI 等主題分類。這是啟動器私人清單，不會改變 YouTube 帳號的訂閱。

支援 youtube.com/@帳號、/channel/UC...、/user/... 等頻道網址。請貼實際頻道連結，而非搜尋頁網址。

🎬 我的待播清單

自己貼影片、Shorts、直播或播放清單連結，安排「待播 → 觀看中 → 已看完」，不怕想看的內容被推薦演算法沖走。

↗ 開啟 YouTube 原生「稍後觀看」

原生「稍後觀看」的內容無法透過 YouTube Data API 直接讀取，因此這裡的待播清單獨立管理；播放或標記已看不會更動 YouTube 原生清單。

💾 我的影音資料備份

頻道、待播清單、個人觀察筆記目前儲存在這個瀏覽器。換手機、換瀏覽器時，可匯出 JSON 檔並在另一裝置匯入；相同連結會自動略過。

資料不會自動寫入 GitHub，也不會自動同步到 YouTube 帳號。
