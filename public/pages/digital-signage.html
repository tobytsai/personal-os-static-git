從 Google 試算表載入資料

在試算表分頁中選「檔案 → 下載 → 逗號分隔值（CSV）」，可依序下載五個分頁，再一起選取檔案匯入。需包含正確的標題列；資料只用於本機預覽。

目前顯示預設示範資料。正式上線前請在試算表填入實際內容並完成審核。

海報作品

點選「預覽」可全螢幕觀看單張。示範資料不可直接發布。

範本設定

可在試算表修改比例、顏色、字級及圖片配置。

播放清單

相同清單 ID 可加入多張海報，依「播放順序」排列。停留時間以秒計。

排程管理

依裝置與時段安排播放。示範排程目前均關閉。

版本紀錄

每次修改都新增一筆版本歷史，不覆蓋原有紀錄。

操作與發布流程

① 在試算表編輯

將海報資訊填入 海報資料，並參照 範本設定 的 T-xxx。WebP 輕量圖放 GitHub；原始圖片放 Google Drive。

② 安排播放內容

在 播放清單 建立 L-xxx，指定海報 ID、順序與秒數；在 排程管理 設定裝置、日期與台北時間。

③ 匯入並本機預覽

從試算表分別下載 CSV，於本頁一次匯入。只有正在使用的瀏覽器能查看匯入資料，不會保存到 GitHub 或伺服器。

④ 確認公開資格

正式發布需要 內容狀態＝已發布、允許公開＝是，且清單與排程皆為啟用。未達條件不會放入公開 JSON。

⑤ 產生公開快照

下載 digital-signage-public.json，核對內容與圖片公開權限後，才更新 GitHub 中同名檔。這個步驟目前是人工審核，不是假自動同步。

⑥ 進入全螢幕輪播

正式播放頁依已發布排程、指定裝置 ID 與台灣時間決定內容；網址可加 ?mode=public&screen=螢幕ID。
