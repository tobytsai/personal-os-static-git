🔔 Personal OS｜LINE 到期提醒

用現有的「首頁提醒」私人 Google 試算表，透過 Google Apps Script 每日檢查期限，再送到你已建立的 Personal OS LINE 通知中心。

這不是公開雲端資料，不需要在 GitHub 存放個人提醒，也不需要完成首頁尚未成功的 OAuth 彈出視窗流程。

一、建立與私人試算表綁定的 Apps Script

  1. 用你的 Google 帳號打開現有的 「首頁提醒」Google 試算表（分頁名稱必須是 reminders）。
  2. 在試算表上方點 「擴充功能 → Apps Script」。Android Chrome 可先啟用「電腦版網站」顯示這個選單。
  3. 打開 Personal OS LINE 提醒程式（完整原始碼），複製整份內容，貼到 Apps Script 的 Code.gs 編輯器，取代預設範例，再按儲存。請先核對來源是你自己的 GitHub 專案。

二、設定 LINE 授權（不要貼到聊天或公開 GitHub）

Apps Script 左側 「專案設定（齒輪）→ 指令碼屬性（Script properties）」，新增兩項：

  1. LINE_CHANNEL_ACCESS_TOKEN：LINE Developers 的 Messaging API Channel access token（不是 Channel secret，也不是 Channel ID）。
  2. LINE_TO_USER_ID：相同 LINE Channel 的 Basic settings 頁面內，以 U 開頭的 Your user ID。

LINE 設定：LINE Developers Console。GitHub Secrets 中已儲存的 Token 無法重新顯示，因此應從 LINE Developers 複製目前有效的 Token。

安全提醒：不要把 Token 貼入公開的網頁、試算表欄位、GitHub 程式碼或聊天。Apps Script 的指令碼屬性只允許受信任的專案編輯者管理，請保持私人試算表不公開。

三、一次性測試並安裝每日排程

  1. 回到 Apps Script 的編輯器，上方函式選單選擇 sendLineReminderTest，按 「執行」，依照 Google 顯示的權限內容確認授權。這一則測試訊息不會把正式提醒標記為已送達。
  2. 確認手機 LINE 收到「✅ Personal OS｜私人提醒 LINE 測試成功」。
  3. 上方函式選單改成 installLineReminderTrigger，再按 「執行」。程式會建立每天台灣時間約 08:30 的定時觸發條件。
  4. 在 Apps Script 左側「觸發條件（時鐘圖示）」確認 checkLineReminders 的觸發條件已建立。Google 時間型觸發條件可能在指定時間附近稍有偏差。

以後不必每天開啟網頁，Apps Script 的定時觸發條件會自行檢查這份私人試算表。

四、何時才會收到 LINE？

一般提醒：到期前 7、3、1 天以及到期當天。機車排氣定檢：到期前 30、7、1 天以及到期當天。完成（done=TRUE）或刪除（deleted=TRUE）的提醒、沒有日期的提醒，都不發送。

同一則提醒的同一個日期、同一階段只會送一次；同一天多筆符合的提醒會合併成一則 LINE 以節省訊息額度。

請注意：目前你的 Personal OS 首頁 Google OAuth 還沒成功連接，因此手機瀏覽器本機新增／完成／刪除的提醒，不會自動同步到試算表。LINE 只能看到私人 reminders 工作表中實際存在的資料。你可以先直接在試算表修改提醒，之後再完成首頁 OAuth 同步。

五、查看狀態或停止通知

在 Apps Script 左側「執行項目」可以看到每日檢查的成功或錯誤狀態。沒有到期提醒時會顯示「今天沒有新的符合條件提醒」，並且不發 LINE。

要暫停排程，在函式選單選擇 stopLineReminderTrigger 執行；這不會刪除私人提醒、LINE Token 或已發送的紀錄。

Google 官方參考：Apps Script 時間型觸發條件、指令碼屬性。LINE 官方參考：Messaging API 訊息發送。
