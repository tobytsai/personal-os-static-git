私人提醒雲端同步設定

這是選用功能。未連線時維持原本本機提醒；私人試算表不需公開或發布成網頁。請使用自己的 Google 帳戶完成以下設定，不要提供登入密碼、client secret 或存取權杖。

  1. 在 Google Cloud Console 選擇或建立自己的專案，啟用 Google Sheets API、Google Drive API、Google Picker API。
  2. 設定 Google Auth Platform 同意畫面；若應用程式為 External / Testing，將自己的 Google 帳號加入測試使用者。設定僅使用 https://www.googleapis.com/auth/drive.file。本功能不要求整個雲端硬碟或所有試算表權限。
  3. 建立 Web application OAuth Client ID，授權 JavaScript 來源填入 https://tobytsai.github.io（不包含路徑）。這個 token popup 流程不需要 redirect URI。把 Client ID 填到首頁設定；不要填 Client secret。
  4. 在同一專案建立 API key，Application restrictions 選 Websites，允許 https://tobytsai.github.io/* 及 Picker iframe 使用的 https://docs.google.com/*；API restrictions 僅允許 Google Picker API、Google Drive API。填入首頁 API key 欄位。這是瀏覽器使用的公開識別金鑰，應加來源與 API 限制；不要使用伺服器密鑰。
  5. 到專案設定複製「專案編號」（數字，不是專案 ID），填入首頁。OAuth Client ID、API key、專案編號必須來自同一專案。
  6. 按「連線 Google」，自行登入授權；再按「選擇提醒表」，在 Google Picker 選擇私人提醒試算表。提醒表必須有 reminders 分頁，第一列 A:L 依序為 id,title,date,phone,done,url,source,order_id,message_id,received_at,updated_at,deleted。其餘資料列由新增提醒產生，不要重新排列欄位。
  7. 連線只讀取雲端，不會把本機提醒上傳；需要時另按「上傳本機提醒」並確認。已存在的 ID（包括完成、刪除紀錄）不會被匯入覆蓋。
  8. 其他裝置重複輸入設定、登入並選擇同一份試算表。用一則不含個資的測試提醒驗證新增、完成、刪除，在另一裝置按「重新整理雲端」確認。

資料與同步限制

  • 設定與選中的試算表 ID 只保存在此瀏覽器，沒有寫入公開網站原始碼。權杖只存在記憶體；重新載入或到期需重新登入，不會在載入首頁時跳出登入。
  • 「中斷連線／回本機」清除此頁的權杖並返回本機提醒，不會刪除雲端資料，也不會撤銷 Google 帳戶上的既有同意。可到 Google 帳戶連線設定撤銷。
  • 每次寫入前會先讀取最新資料，僅修改目標欄位；刪除使用 deleted=TRUE，不刪除實體列。不要同時在其他裝置編輯同一提醒、刪除或排序實體列。Sheets 沒有此功能所需的原子比較交換保證；極短時間內同欄修改仍可能後寫覆蓋。
  • 無自動背景輪詢、推播或 Gmail 監控；按重新整理取得最新資料。網路失敗時先重新整理確認，再重試。到期時按連線 Google。既有本機與雲端為不同清單。
  • 期限未知可留空；「配達日」不是取件截止日。連結只允許 HTTPS，Gmail 信件標示為 Gmail 通知，不冒充商品頁。
  • 此功能經模擬 API 測試；瀏覽器 UI 測試受執行環境限制尚未完成；真實 Google 授權、Picker 存取與雙裝置同步仍需依上面步驟驗證。Gmail 自動辨識取件通知需另行確認，不會因開啟同步而啟用。
